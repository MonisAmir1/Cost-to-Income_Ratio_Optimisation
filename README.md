## About the Project

ABC Banking Group is a fictional mid-sized banking institution headquartered in Luxembourg.

This project investigates the escalation of the bank's Cost-to-Income (C/I) Ratio over a five-year period (2021–2025), using financial, operational, workforce, and process-level data to investigate the underlying business drivers.

The analysis was approached as a real-world Data Analysis project: starting with the business problem, analysing the available evidence, identifying the underlying operational drivers, and translating the findings into practical recommendations.

## Objective

The objective was to understand:

- How and why the bank's Cost-to-Income Ratio was escalating.
- Which areas of the organisation were contributing to the change.
- Where operational inefficiencies were occurring.
- How data could be used to support targeted operational improvements.

## Project Approach

The investigation followed a progressive analytical approach, moving from high-level financial performance towards operational-level analysis.

**Business Problem → Financial Analysis → Cost Analysis → Department Analysis → Process Analysis → Root Cause**

This allowed the analysis to identify the underlying drivers from the data rather than assuming the cause in advance.

## Key Result

The analysis identified a significant escalation in the bank's Cost-to-Income Ratio and traced the underlying issue from financial performance through to operational process inefficiencies.

The project demonstrates how SQL and Power BI can be combined to move from a high-level business problem to evidence-based operational decision support.

## Data

This project uses a **real-world synthetic dataset** created specifically for portfolio purposes. It does not contain real banking, customer, employee, or confidential financial data.
